# 需求规格说明书

## 1. 目标

系统用于集中管理百度网盘分享链接，浏览分享目录，并将指定远端目录增量同步到
Windows、Linux 或 macOS 本机目录及操作系统挂载的 SMB NAS。

## 2. 用户与权限

- 用户与密码保存在 SQLite `users` 表中，密码使用带随机盐的 scrypt 哈希；系统不再
  从文件读取或写入明文密码。
- 首次部署或数据库中没有用户时自动创建默认管理员 `admin / admin123`，登录后可在
  界面修改密码。
- 角色包含管理员 `admin` 和普通用户 `user`。
- 管理员拥有全部页面和操作权限。
- 普通用户可分别获得分享链接、同步映射、任务中心、系统配置页面权限。
- 所有权限必须由后端校验，不能只隐藏前端导航。

## 3. 功能需求

1. 登录、退出和七天会话。
2. 分享链接的新增、编辑、删除、刷新和逐级目录浏览。
3. 同步映射的新增、编辑、删除、连接检测、单项同步和全部同步。
4. 支持本机路径和操作系统挂载的 SMB 路径。
5. 支持手动同步和按映射配置的分钟间隔自动同步。
6. 任务中心的当前任务仅显示排队或运行中的任务，已完成或失败的同步任务显示在持久化同步历史中。
7. 系统配置页显示只读部署信息，并允许在页面维护系统名称、日志保留天数、当前账号
   密码和多网盘 Cookie；Cookie 区域显示名称、脱敏摘要、添加时间、最近校验时间及
   未知/有效/无效状态。
8. 权限管理页维护用户密码、角色和页面权限；任务中心由管理员维护任务并发数、
   自动同步调度间隔和同步历史保留策略。
9. 同步映射提供“查看”操作，以弹窗展示该映射同步到本地的文件，每个相对路径展示最新同步记录。
10. 当前同步任务或同步历史存在成功同步文件时，可查看该次运行的文件列表。
11. 同步文件弹窗显示文件名、相对路径、同步动作和北京时间，并支持按文件名、同步时间升降序排序。
12. 仅成功新增或更新到本地的文件记入同步文件记录；跳过、删除和失败文件不记为成功同步。
13. 同步文件查询必须校验同步映射或任务中心页面权限，不得提供任意本地文件系统浏览能力。
14. 管理员可新增、修改、校验和删除 Cookie；系统配置页普通用户只能查看脱敏元数据。
15. 每条分享链接关联一条 Cookie，所有索引、刷新、浏览、下载和同步均使用关联凭据。
16. 被分享引用的 Cookie 不得删除；网络和百度风控不得被误判为 Cookie 无效。
17. 旧单 Cookie 幂等迁移为默认 Cookie；`BDPAN_COOKIE` 保持只读且不得写入磁盘。
18. 文件版本元数据不得依赖原文件名长度；系统使用独立元数据目录和稳定哈希文件名，
    并兼容读取已有的 `原文件名.bdpan`。
19. 自动同步失败后必须记录尝试时间并执行持久化指数退避，调度轮询不得重复提交尚在
    退避期的映射；百度 `errno=-65` 使用更长退避并提示安全验证或频率限制。
20. 退避到期后映射可恢复自动调度；成功后清除连续失败状态。
21. 同步历史必须按保留天数及每映射最大运行数清理，防止重复失败无限占用数据库。
22. 浏览器标签页显示系统图标：`index.html` 引用 `/favicon.svg`（现代浏览器）与
    `/favicon.ico`（兼容回退），由后端直接提供这两个静态文件，无需登录。
23. 分享链接状态必须反映最近一次检测结论：网盘明确返回分享不存在、已删除、已取消、
    已过期或封禁受限时标记为“已失效”；网络异常、限流、风控和提取码错误不得误判为
    失效；超过 30 天未成功检测的“有效”链接在页面显示为“待检测”。
24. 用户可通过界面修改自己的密码；管理员可在权限管理页新增用户或重置任意用户密码。
25. 系统配置页和任务中心只允许管理员修改配置；普通用户如有对应页面权限可查看，
    但不能修改。
26. 页面可维护的配置必须原子写回 `config/app.json`；`task_workers` 需重启服务生效，
    其余可维护项保存后生效。
27. 升级时如存在旧版 `data/password.txt`，系统一次性导入数据库中尚不存在的用户，
    成功后删除明文文件；数据库已有用户不得被旧文件覆盖。

## 4. 非功能需求

- 后端使用 Python、FastAPI、SQLite；前端使用 Vue 3。
- 支持 Windows、Linux、macOS。
- 密码以 scrypt 哈希存入数据库，Cookie 原文与会话密钥不返回浏览器；Cookie 元数据
  存 SQLite，原文按 ID 存入权限受限的 `secrets.json`。
- 时间按北京时间显示，日志按天轮转。
- SMB 掉线时禁止向失效挂载点下的本机目录写入文件。
- Linux 单个文件名接近 255 字节时，元数据读写仍须正常；测试覆盖 ASCII、中文和混合
  UTF-8 文件名。


## 多网盘支持（2026-10-25）

- 支持百度网盘、夸克网盘分享的添加、提取码识别、目录索引与浏览、刷新、同步和定时任务。
- FastAPI、Vue、SQLite 及现有登录、权限、任务中心、同步策略保持兼容；包名、CLI 命令、服务名称和访问地址沿用原值。
- 分享记录与 Cookie 元数据增加 `provider`（`baidu` / `quark`）。启动时自动补充数据库字段，历史记录默认为百度网盘，无需手工迁移。
- 在系统配置页添加 Cookie 时选择网盘类型：百度需要 `BDUSS`，夸克需要 `__puus`。Cookie 原文继续仅存于服务端 secrets.json；分享与凭据类型必须一致，已建分享不可直接切换网盘类型。
- 添加分享时可直接粘贴 `https://pan.quark.cn/s/分享ID?pwd=提取码` 或带中文提取码的文本，选择同网盘凭据。
- 夸克下载先将文件转存到所选账号的根目录，再获取下载地址。转存文件保留、占用网盘容量；再次同步更新文件可能产生额外转存。容量不足或接口拒绝时任务失败并保留错误日志。
- 夸克 API 使用 Web 接口，可能随平台更新或风控失效。可通过环境变量 `QUARK_API_URL` 覆盖 API 基址（默认 `https://drive-pc.quark.cn/1/clouddrive`）。需要有效账号 Cookie；模拟接口测试不能代替真实账号验收。
- CLI 同样按分享类型分派客户端；例如 `bdpan config --provider quark --name 夸克账号 --cookie '完整Cookie'`，添加分享时可用 `--cookie-id` 指定凭据。
- Jenkins 增量更新排除 `config/app.json`，仅首次部署复制默认配置，保留线上 data、日志与配置。升级前建议备份 SQLite、secrets.json 和配置文件。

Linux 运维脚本会优先管理已安装的 systemd 单元（环境变量 `BDPAN_SYSTEMD_UNIT`，默认 `baidupan.service`），否则使用原 PID 模式。Jenkins 用户需获准以 sudo 无密码执行对应单元的 start/stop；本次部署已添加仅限该单元启停的规则。

## 账号与配置界面维护（2026-11-07）

- 账号密码改为仅保存在 SQLite，不再创建、读取或写入明文密码文件；首次启动且数据库
  没有用户时自动创建 `admin / admin123`，并保证系统至少有一个可用管理员。
- 登录用户可通过左下角“密”按钮或系统配置页的“账号安全”修改自己的密码；管理员继续
  在权限管理页新增用户和重置密码。
- 系统配置页可维护系统名称和日志保留天数；任务中心可维护任务并发数、自动同步调度
  轮询间隔、同步历史保留天数和每映射最大运行数。
- 页面维护的配置原子写回 `config/app.json`。任务并发数需重启服务生效，其余保存后
  生效；监听地址、端口、时区和文件路径仍为只读部署参数。
- 升级时若存在旧版 `data/password.txt`，一次性导入数据库中尚不存在的用户后删除该
  明文文件，数据库已有用户不被覆盖。
