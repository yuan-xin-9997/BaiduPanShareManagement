# 需求规格说明书

## 1. 目标

系统用于集中管理百度网盘分享链接，浏览分享目录，并将指定远端目录增量同步到
Windows、Linux 或 macOS 本机目录及操作系统挂载的 SMB NAS。

## 2. 用户与权限

- 用户由 `data/password.txt` 维护，格式为 `username:password:role`。
- 角色包含管理员 `admin` 和普通用户 `user`。
- 管理员拥有全部页面和操作权限。
- 普通用户可分别获得分享链接、同步映射、任务中心、系统配置页面权限。
- 所有权限必须由后端校验，不能只隐藏前端导航。

## 3. 功能需求

1. 登录、退出和七天会话。
2. 分享链接的新增、编辑、删除、刷新和逐级目录浏览。
3. 同步映射的新增、编辑、删除、连接检测、单项同步和全部同步。
4. 支持本机路径和操作系统挂载的 SMB 路径。
5. 支持手动同步和按映射配置的分钟间隔自动同步。
6. 任务中心的当前任务仅显示排队或运行中的任务，已完成或失败的同步任务显示在持久化同步历史中。
7. 系统配置页显示运行配置，并显示多条 Cookie 的名称、脱敏摘要、添加时间、最近校验
   时间及未知/有效/无效状态。
8. 权限管理页维护用户密码、角色和页面权限。
9. 同步映射提供“查看”操作，以弹窗展示该映射同步到本地的文件，每个相对路径展示最新同步记录。
10. 当前同步任务或同步历史存在成功同步文件时，可查看该次运行的文件列表。
11. 同步文件弹窗显示文件名、相对路径、同步动作和北京时间，并支持按文件名、同步时间升降序排序。
12. 仅成功新增或更新到本地的文件记入同步文件记录；跳过、删除和失败文件不记为成功同步。
13. 同步文件查询必须校验同步映射或任务中心页面权限，不得提供任意本地文件系统浏览能力。
14. 管理员可新增、修改、校验和删除 Cookie；系统配置页普通用户只能查看脱敏元数据。
15. 每条分享链接关联一条 Cookie，所有索引、刷新、浏览、下载和同步均使用关联凭据。
16. 被分享引用的 Cookie 不得删除；网络和百度风控不得被误判为 Cookie 无效。
17. 旧单 Cookie 幂等迁移为默认 Cookie；`BDPAN_COOKIE` 保持只读且不得写入磁盘。

## 4. 非功能需求

- 后端使用 Python、FastAPI、SQLite；前端使用 Vue 3。
- 支持 Windows、Linux、macOS。
- 密码以 scrypt 哈希存入数据库，Cookie 原文与会话密钥不返回浏览器；Cookie 元数据
  存 SQLite，原文按 ID 存入权限受限的 `secrets.json`。
- 时间按北京时间显示，日志按天轮转。
- SMB 掉线时禁止向失效挂载点下的本机目录写入文件。
