## Why

当前同步映射和任务记录只能展示同步状态，用户无法确认某个映射或某次任务实际同步了哪些本地文件；同时，已完成任务仍出现在“当前任务”中，导致运行态信息与历史信息混杂。需要补齐同步文件的可追溯查看能力，并明确当前任务与同步历史的展示边界。

## What Changes

- 在同步映射列表为每条映射增加“查看”操作，通过弹窗展示该映射已同步到本地的全部文件。
- 在任务中心将“当前任务”限定为正在运行的任务，已完成或失败的同步任务仅保留在同步历史中。
- 当前运行任务和同步历史记录在存在新增同步文件时提供查看入口，通过统一弹窗展示该任务/同步记录对应的文件。
- 文件弹窗展示文件名、同步时间等信息，并支持按文件名、同步时间升序或降序排序。
- 持久化文件与同步映射、同步运行记录之间的关联，确保页面刷新或服务重启后仍可查询。

## Capabilities

### New Capabilities

- `synced-file-traceability`: 记录并查询同步到本地的文件，支持按同步映射或同步任务/运行记录查看和排序。

## Impact

- SQLite 数据结构及迁移逻辑：新增同步文件记录或等效的可追溯数据结构。
- 同步执行与后台任务：在文件成功落地后记录所属映射、同步运行、文件名/路径及同步时间。
- FastAPI：增加按映射、任务或同步运行查询同步文件的受权限保护接口，并调整当前任务返回规则。
- Vue 任务中心与同步映射页面：增加“查看”入口、文件弹窗、空状态和排序交互。
